# Durga Khasta Corner — Website

A one-page website for Durga Khasta Corner, a legendary breakfast shop on Latouche Road, Lucknow, serving crisp Khasta and Bada with white peas, spicy potatoes, onion and green chilli for over 80 years.

- Address: 91/19, Latouche Road, Ghasyari Mandi, Naka Hindola, Lucknow 226001
- Phone: +91 89608 32873
- Hours: Daily 4:00 AM – 3:00 PM

Built as a single static `index.html` (Tailwind via CDN). Details are taken from public listings (Justdial, Google Places, Times Now, NowLucknow) and can be updated by the owner at any time.
